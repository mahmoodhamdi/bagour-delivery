# customer-web

Bagour Delivery's customer-facing PWA. Next.js 16 + Tailwind v4 + next-intl (AR/EN) + Serwist (PWA) + TanStack Query + Zustand.

## Quick start

```bash
pnpm install            # from repo root
cp customer-web/.env.example customer-web/.env.local
pnpm --filter customer-web dev
```

Visit http://localhost:3000 — defaults to Arabic; toggle to English from the header.

## Stack snapshot

| Layer | Pick |
|---|---|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript strict, `noUncheckedIndexedAccess` |
| Styling | Tailwind v4 + `@bagour/config-tailwind` brand tokens |
| Fonts | Cairo via `next/font/google` (subsets: arabic + latin, weights 300-900) |
| i18n | `next-intl` v3, AR default, RTL aware via `dir="rtl"` |
| State (server) | TanStack Query v5 (provider wired in PR-1.2 layout shell) |
| State (client) | Zustand |
| Forms | react-hook-form + Zod |
| API | `@bagour/api-client` (workspace) |
| Realtime | `socket.io-client` (wired in PR-3.1 tracking) |
| PWA | Serwist (`@serwist/next`) — disabled in dev, enabled in build |

## i18n routing

- Default locale `ar` is served without a prefix (`/`, `/restaurants`).
- English is at `/en`, `/en/restaurants`, etc.
- Middleware (`src/middleware.ts`) handles the redirect logic.
- Messages live in `messages/{ar,en}.json`.

## PWA

- Manifest is generated by Next at `/manifest.webmanifest` from `src/app/manifest.ts`.
- Service worker source: `src/app/sw.ts` (compiled to `public/sw.js` by Serwist on build).
- Brand color: `#cf6f2c` (Bagour orange). Background: `#fdfaf6`.
- Install prompt + offline shell ships in PR-4.1 (offline pass).

## Testing

```bash
pnpm --filter customer-web test        # vitest unit + component
pnpm --filter customer-web test:e2e    # playwright (needs `pnpm build`)
pnpm --filter customer-web test:watch  # interactive
```

- Vitest config in `vitest.config.ts`; setup file `src/test/setup.ts` wires `@testing-library/jest-dom`.
- Playwright config: `playwright.config.ts`. Five projects: chromium / firefox / webkit / mobile-chromium / mobile-safari. The `webServer` block boots `pnpm start` for E2E.
- Accessibility checks via `@axe-core/playwright` inside E2E (`home.spec.ts`).

## Customizing the brand

The brand colors live in `@bagour/config-tailwind/brand.css`. To re-skin per client without forking, override the `--brand-*` CSS variables in `src/app/globals.css` **after** the brand import.

## Security headers

Set in `next.config.ts`: HSTS, X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy strict-origin-when-cross-origin, Permissions-Policy (camera + geolocation allowed to self only). Strict CSP with nonces lands in PR-9.1 once dynamic features are in place.
